The comparison is code, not eyesight: the verdict below is computed.

      The self-hosted stack is grammar/lexer.planes,
      grammar/parser.planes and grammar/interp.planes —
      the same files test_js_metacircular.py checks against the
      Python implementation on every gate run. This page fetches them as
      .planes sources at run time, so it needs the folder as well as
      the modules. Opens directly in Safari or Firefox. Chrome blocks ES-module
      loading over file:// as a security policy — for Chrome, serve
      the folder with python3 -m http.server and open
      http://localhost:8000/. No bundler, no transpiler.
