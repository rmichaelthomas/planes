A canvas runtime that adds nothing to the language: a program draws by emitting show lines carrying the versioned drawing protocol — every line prefixed draw, twenty-six verbs, OKLCH colour (see the footer) — usually through use draw's helpers rather than assembled by hand, and the page paints them. Input crosses in as a value, not an effect; state crosses the tick boundary through write state to "state.json", one direction. The effect surface beside the canvas is computed, not declared — the same analyser index.html uses, now following use across the module graph too — and it is never hidden.

There are two renderers now, and the program cannot tell which is listening. The canvas below and the SVG the Save button writes walk the same stream through the same module; only what they do with a circle differs. That is what the protocol is for.

Drawing Protocol v1 — twenty-six verbs, every line prefixed draw: colour and line (stroke, fill, width, cap, corner), shapes (line, rect, circle, ellipse, arc, triangle), paths (shape, vertex, curve, close, end), transforms (push, pop, translate, rotate, scale), text and canvas (label, size, align, background, clear). Colour is OKLCH (L C H, plus A for stroke/fill). A line not beginning with draw goes to the output pane as text, unconditionally; a line that does begin with draw is always a command, and a malformed one is reported as an error rather than drawn.

Two renderers. The canvas and the SVG exporter are sinks for one stream walk (js/paint/stream.mjs): the version declaration, the path lifecycle, transform balance, the arc convention and every error tag are written once and shared, so the two cannot drift apart. Saving. SVG and PNG capture the frame that is on screen — for a program that redraws continuously that is a snapshot, not an animation. PNG is written at twice the device pixel ratio. Video records ten seconds of the canvas as WebM. A saved SVG's labels are laid out by whatever font resolves where the file is opened, so text may shift on another machine; both renderers name the same family, and nothing can make that hold everywhere.

Opens directly in Safari or Firefox. Chrome blocks ES-module loading over file:// as a security policy — for Chrome, serve the folder with python3 -m http.server and open http://localhost:8000/paint.html. No bundler, no transpiler, no network dependency: the page loads the real js/*.mjs modules, the real grammar/*.json as JSON modules, and the paint/*.planes programs and libraries as plain text, all from this same directory.
