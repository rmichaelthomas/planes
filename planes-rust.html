Planes, Rust, and the same work

This small experiment implements two existing Planes H7 workloads in a bounded Rust runtime: 2,000 immutable record updates and 5,000 exact-decimal invoice lines. The browser runs matching JavaScript and Rust/WebAssembly implementations against the same inputs, checks their output, then times repeated runs.
