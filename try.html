A complete Planes implementation — lexer, parser, interpreter, and static effect analyser — running in your browser, with no Python and no build step. Run ▸ executes the program; Surface ⊚ tells you what it would touch — which boundaries, which destinations — without running a line of it.

The surface is computed by js/shapes.mjs — the same analyser as shapes.py, checked against it — and it never executes the program. Opens directly in Safari or Firefox. Chrome blocks ES-module loading over file:// as a security policy — for Chrome, serve the folder with python3 -m http.server and open http://localhost:8000/. No bundler, no transpiler: the page loads the real js/*.mjs modules and the real grammar/*.json as JSON modules.
