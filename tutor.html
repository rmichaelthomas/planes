Serving: this page fetches paint/scene.planes and paint/draw.planes and imports js/*.mjs as ES modules, so it needs a static server (python3 -m http.server 8000) and no network beyond it.

The editor is the source pane. There is no second, read-only listing of the program — clicking a mark on the picture marks the line in the textarea above that drew it. Asking performs nothing: a question reads the derivation the last Run already produced, and the effect surface above is computed without running a line.

Saving. SVG and PNG capture the picture on screen, from the last successful Run — never a fresh run.
